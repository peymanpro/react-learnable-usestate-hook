# react-learnable-usestate-hook

A TypeScript implementation of a learning-enabled extension of React state.

## Status

Early development.

This package is being developed as a reference implementation experiment
based on the architectural concepts of the Learning-Native Adaptive Software Framework (LNASF).

The current version does not claim empirical validation or novelty of the
underlying mathematical techniques.

## Research Provenance

Original LNASF specification:

https://github.com/peymanpro/learning-native-adaptive-software-framework

Zenodo record for the referenced LNASF release:

https://doi.org/10.5281/zenodo.22141992

The package is an implementation experiment derived from the architectural
concepts described in LNASF. The underlying mathematical and software
engineering techniques used by the implementation are not presented as
individually novel.

## Development

Install dependencies:

pnpm install

Type-check:

pnpm run typecheck

Run tests:

pnpm test

Build:

pnpm run build
